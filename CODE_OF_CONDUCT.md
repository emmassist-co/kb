# Code Of Conduct

## Our Standard

This project expects respectful, professional collaboration in issues, pull requests, discussions, and release work.

Examples of acceptable behavior:

- asking precise technical questions
- giving actionable review feedback
- correcting mistakes without personal attacks
- sharing context that helps others reproduce or verify a result

Examples of unacceptable behavior:

- harassment, insults, or demeaning language
- publishing private information without consent
- intentionally disruptive review or issue behavior
- bad-faith participation that blocks maintainers or contributors

## Scope

This applies across the repository, issue tracker, discussions, release coordination, and other project communication channels.

## Enforcement

Project maintainers may remove comments, close threads, reject contributions, or block participation when behavior violates this standard.

## Reporting

For conduct concerns, report privately using the security contact path in [SECURITY.md](./SECURITY.md).
