# Security Policy

## Reporting A Vulnerability

Do not open public GitHub issues for suspected security vulnerabilities.

Instead, email:

- `security@emmassist.co`

Include:

- affected package or runtime surface
- reproduction steps
- impact assessment
- any suggested mitigation

We will acknowledge receipt, assess severity, and coordinate a fix and disclosure plan.

## Scope

Report issues involving:

- auth or tenant isolation failures
- data exposure across tenants
- secret handling
- deployment or supply-chain compromise
- unsafe write paths in canonical KB surfaces
